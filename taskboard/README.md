# タスクボード（Web配布用）

本日／今週のタスクを表示する、単一HTMLのタスク管理ツールです。

## 置き方・開き方
1. この `taskboard` フォルダを GitHub リポジトリに置く
2. そのリポジトリで **GitHub Pages を有効化**（Settings → Pages → Branch: main / (root)）
3. 数分後、次のURLで開けます
   `https://<アカウント名>.github.io/<リポジトリ名>/taskboard/`
4. ブラウザで開き、アドレスバー右端の **「インストール」アイコン** から
   「アプリとしてインストール」すると、枠なしのアプリ窓で使えます
   （インストールできない環境では、タブのままでも使えます）

- データ保存：各端末のブラウザ内（localStorage）。外部送信なし。
- 元コード：`ueshima-blip/my-tools` の `apps/task-board`
